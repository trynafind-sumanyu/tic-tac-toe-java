# 🎮 Tic Tac Toe (Java Console Game)

A simple 2-player Tic Tac Toe game built using Java. This project is a great way to understand basic programming concepts like arrays, loops, conditionals, and method design.

---

## 🚀 Features

* 🧑‍🤝‍🧑 Two-player gameplay (Player X vs Player O)
* ✅ Input validation (prevents overwriting moves)
* 🧠 Win detection (rows, columns, diagonals)
* 🤝 Draw detection
* 🖥️ Clean console-based UI

---

## 🛠️ Tech Used

* Java (Core Java)
* Scanner for user input
* Arrays for board representation

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/tic-tac-toe-java.git
```

2. Navigate to the project folder:

```bash
cd tic-tac-toe-java
```

3. Compile the Java file:

```bash
javac TicTacToe.java
```

4. Run the program:

```bash
java TicTacToe
```

---

## 🎯 How to Play

* The game is played on a 3x3 grid.
* Players take turns entering row and column values.
* Example input:

```
0 0  → Top-left corner
1 1  → Center
2 2  → Bottom-right
```

* First player to align 3 marks (row/column/diagonal) wins.
* If all 9 moves are filled with no winner → Draw.
